A etapa 1 do projeto foca em estabelecer as fundações de engenharia, banco de dados e documentação:

1. Formação do grupo (3 a 5 alunos).

2. Criação do repositório PÚBLICO "PROJETO-MESAFARTAI" no GitHub.

3. Criação do README.md com título, alinhamento à ODS 2 e integrantes.

4. Criação da pasta /docs contendo as regras.txt e o escopo_projeto.md (com o prompt da IA do logotipo).

5. Geração da identidade visual via IA, salva em assets/logo_mesafartai.png.

6. Inclusão dos diagramas de arquitetura e fluxo na pasta /docs.

7. Criação do script src/database.py para criar as tabelas e carga inicial de teste no SQLite (mesafartai.db).

REGRAS INTERNAS E REQUISITOS - ETAPA 2 (NLU e Ambiente Local)

1. Clonar o repositório localmente via terminal (`git clone` e `cd`).

2. Abrir a pasta no VS Code, criar o arquivo `requirements.txt` na raiz (com streamlit, scikit-learn, pandas e numpy) e instalar as dependências (`pip install -r requirements.txt`).

3. Criar o arquivo `src/nlu.py` com o Motor NLU configurado (pipeline TF-IDF, Random Forest e Trava de Segurança/Fallback).

4. Executar e testar o script localmente no terminal (`python src/nlu.py`).

5. Realizar o commit e push das alterações para o GitHub (`git add .`, `git commit` e `git push origin main`).
